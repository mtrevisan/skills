# HRC 4.1 — KNOWLEDGE (sections A–E, G; F = FALLBACK.md, only without code tool)

## A. INPUT, PARSER & METROLOGY
- **Input** = target recipe + similar recipes + bibliography with measure tables (or none → fetch online and cite URL/page). The request names a year/title; several matches → analyze the first, list the others as concordance and say so in Notes.
- **Footnote `[^n]` = link to a bibliography entry** (source or measure table). If the same id points to two entries, pick by the place/work named next to it ("Misure di Padova") and by content, and say so in Notes.
- Source `[ ]` text is commentary: ignore it for computation; a metric inside it that contradicts the calculation → keep the calculation, note it; a botanical name inside it fixes `taxon`. `NOTA`/sub-recipes in the input are a Batch Layer: they may define an ingredient ("capi di latte" = cream skimmed from milk) and are integrated into the procedure.
- Post-metric recipe (no historical units): use g/ml directly, declare it once in TA.
- **Identification** (every ingredient, any language or period; E refuses an ingredient without `ident`). Procedure, in this order, stop at the first success:
  1. The input itself: glossary, notes, bibliography, a similar recipe that names the same thing.
  2. Search the web: dictionaries and glossaries of that language AND period (historical and dialect dictionaries, lexica, editions of the source, botanical/food-history works). Try the spelling variants (double/single consonants, u/v, i/j, x/s, ph/f, with/without h, abbreviations expanded, Latin or vernacular forms of the same word) and the same term in other texts of the same place and years.
  3. Cite each source in `ident.src` (URL + page/entry) and note it in Notes.
  - Set `ident.status`: `KNOWN` = unambiguous modern term or defined in the input (`src` = "input" or "modern term"); `RESEARCHED` = identified by steps 2–3; `UNKNOWN` = nothing found, or several readings that evidence cannot separate. Do not choose between readings: list them in Notes.
  - `UNKNOWN` → `cat:"other"`, no `taxon`, still weighed by its `seed`; its hist line follows the missing-quantity cascade; confidence lowered (E). Never route an unknown ingredient as if it were a known one.
  - A name that looks like a modern word (e.g. a "flour"-like or "milk"-like term) proves nothing: classification (`cat`, `phase`, `function`, `perishable`) comes from the identification, not from the name. A starch-network ingredient can never use a SOTTILE category (E checks `function`, not the name).
  - Same term in the same document → same identification (reuse, do not redo).
- **Routing** (E derives the track; you label `cat`, `vol` from the identification): flour/starch/meal → GROSSO, or DRY_VOLUME if volumetric. spice/sugar/salt/drug → SOTTILE. hydrolat → SOTTILE if weighed, LIQUID_VOLUME if volumetric. fat/meat/cheese/herb/legume/seed/other solids → GROSSO. liquid → LIQUID_VOLUME if volumetric, else GROSSO. Nuts, seeds, bread, cheese, fats are never SOTTILE.
- **Measure tables → `unit_g` / `unit_ml`** (grams or ml per native unit): take only from the input tables or a fetched authoritative source; never from memory. Use the table of the place the recipe names. If a place has two pounds (e.g. "grossa" and "sottile"), choose by track (SOTTILE → sottile, GROSSO → grossa). A table line like "libbra of 12 once, once of 8 dramme, …" is a **chain**: each unit is 1/n of the previous (boccale = secchio/9, bicchiere = boccale/4 …); compute with exact fractions. **A sub-unit not listed for that place (e.g. grano at Padova): search the web first** (metrology tables of that city and period, e.g. the same 1877 "Tavola di ragguaglio" series, other pages of the cited source) and cite URL/page; only if nothing is found → `DATA UNKNOWN` (never borrow another city's subdivision silently). **Price units** ("soldi", "val soldi 4"): search the web for what a soldo bought of that ingredient in that place and period (prices, price lists, calmieri) and cite it; if found set `unit_g` = grams per soldo and `proxy:"price <source>"` (E prints `[PROXY: …]` and lowers confidence); if not found → `DATA UNKNOWN`. Other non-table units ("mesura", counts such as "cavi", "chiare"): search the same way, else no grams. **Count nouns** (apples, eggs): grams per piece from a cited source (`unit_src`); eggs use `egg:true` and E applies its egg model (edible total, albumen, yolk). Every `unit_g`/`unit_ml` needs `unit_src` (input table or URL + page); every quantity needs `src_text` (verbatim fragment of the recipe holding that quantity and unit). Table values with a "pharmaceutical" title are still valid numeric constants (Title Shield: title words never affect routing).
- **Quantities**: `qty_native` integer or fraction, denominator ∈ {2,3,4,6,8,12}, written `1 1/2`, never decimal. E multiplies exactly, no rounding.
- **Missing quantity cascade** (no invention): (1) a similar recipe within ±25 y states it → use it, cite its ID; (2) else `qty_native:null` + `units` (every unit of the place's table chain, each with `unit_g` or `unit_ml` and `unit_src`; `fluid_rho` or the modern `rho` for volumes; every fluid carries `rho`: cited, else 1.025, never 1.0 unless pure water; a table unit in g only or ml only: search the density of that fluid, else deduce it from its composition, convert, print g AND ml, log `rho` and its basis in Notes): E picks the coarsest unit with Q ≥ 1 and error ≤ 1.5 % (fluids volumetric, solids by weight) and prints `[Inferred: Q unit (Y.Y g)]` (L7); (3) else `[Inferred: DATA UNKNOWN] name`, confidence LOW. Log "Inferred Historical Scalar" in TA. The cascade covers every ingredient without a quantity: named in the text, or modern-only (`inferred:true`; e.g. salt, honey, eggs the text omits). Step (2) needs only a measure table (input or cited source). `DATA UNKNOWN` while such a table exists = failure. Every modern row has `hist_ref` = the `name` of one `hist` row.
- A modern ingredient the text never names (e.g. the flour of an unspecified "sfogio de pasta") gets `inferred:true`, its basis (similar recipe or chemistry) in Notes, and lowers confidence.
- **Spice blends** ("specie", "spezie", "spetie fine", "epices", "spices": any generic plural or mix term is a blend, even with an adjective such as "fine"): never one monolithic line. The search is mandatory: input first (glossary, notes, bibliography, similar recipes), then the web; log the result in Notes. Expand to base-12 `parts` from a similar recipe within ±25 y (`hist[].parts`; modern rows one per component). None → search the web for the composition of that blend in the same region and within ±25 y (recipe books, spice lists) and cite it in Notes; use only what the source states. Nothing found → hist row `blend:true` without `parts` and ONE modern spice row under the blend name (weighed, L6 applies; E lowers confidence), never DATA UNKNOWN, never a generic modern mix. Components: modern `name` = the name under `parts`; E matches them by name and sets their weights by the parts. Pre-1850 imported spices: add a Volatile Loss Index remark.
- Time units: Amen 4 s, Ave 15 s, Pater 35 s, Salve 50 s, Miserere 90 s. Taxonomy ` (*Genus species*)` only if verified.
- **Surface items** (garnish/finish): `type:"pure_surface_density"` + `density_g_cm2`; exempt from mass balance; never absolute grams.
- **Concordance** = the similar recipes in the input (verbatim quote ≥10 words in the source language, copied from the input text — never from memory) or entries fetched online with a real page/URL. Each needs Author, Work, Year, Page, one specific philological alignment (e.g. "same cheese:egg-white ratio ±10 %"). Same-source siblings are allowed but flagged. Nothing verifiable → `NONE VERIFIED`. Never invent.

## B. INFERRED TARGETS (E input `inferred_targets`; any dish, not only tarts)
One object per distinct thermodynamic action. Every hydrolat its own object. Keys: `sub_matrix_name`, `target_type` ∈ Emulsion|Gelatinization|Gluten_Network|Protein_Coagulation|Lipid_Plasticization, `primary_objective`, `critical_chemical_constraints{hydration_archetype, lipid_archetype, hydrolat_archetype}`, `involved_historical_ingredients`.
Tokens only — hydration: LIQUID_THIN|LIQUID_THICK|GEL_SOFT|GEL_FIRM|DOUGH_OPEN|DOUGH_DENSE|SOLID_DRY|PROTEIN_COAGULUM|MATRIC_UNSPECIFIED; lipid: EMULSION_O_W|FAT_SHORTENING|LOW_FAT|SOLUTE_OTHER; hydrolat: HYDROLAT_DELICATE_FLOWER|HYDROLAT_AROMATIC_HERB|HYDROLAT_SPICE_BARK|NONE. Use `MATRIC_UNSPECIFIED` for sauces, broths, roasts, spice mixes without a defensible archetype: ratio checks and thermal windows then report `DATA UNKNOWN`/skipped instead of inventing. The only number per target is `starch_saturation_density` (E `starch_sat`).

## C. RHEOLOGY GATE (E; post-evaporation fluid = fluid × e^(−0.0142·evap_min))
GEL_SOFT fluid/starch 1.70–2.70 · GEL_FIRM 0.80–1.70 · DOUGH_DENSE 0.45–0.62 · DOUGH_OPEN 0.62–0.85 · LIQUID_THICK 4–10 · LIQUID_THIN ≥10 · SOLID_DRY ≤0.30 · PROTEIN_COAGULUM fluid/(albumen+yolk) 1.20–3.50 · FAT_SHORTENING lipid/starch ≥0.35 · EMULSION_O_W lipid/fluid >0.82 · LOW_FAT lipid/(fluid+starch) ≤0.05. A skipped check (no starch/egg) is reported in `notes`, never silently passed.
Thermal windows (`thermal_window_C`): starch gelatinization 65–75 °C; egg white 60–65; yolk 65–70; whole-egg binder 80–85; custard gel 78–82. Anything else, or MATRIC_UNSPECIFIED → `DATA UNKNOWN`. Operational fields (pot life min, shearing {tool, speed, duration_min}, rest {duration_min, temp_C}): from the source or chemistry only, else `DATA UNKNOWN`.
HACCP (`haccp`): storage and shelf life are conservative defaults from aw and perishability (aw ≥0.95, or perishable & aw >0.85 → +4 °C 48/96 h; aw <0.60 → ambient 168 h). Allergens are NOT reported. Perishability comes from the ingredient field `perishable` (true|false, from the identification; meat/cheese always true; flour/spice/sugar/salt/drug/hydrolat always false; any other `cat` without the field → treated as perishable and noted). The user must verify the defaults; never extend. aw clamped above the archetype ceiling is expected (bound water): note only; below the floor lowers confidence.

## D. LINTER (silent; render `L1–L17 OK` or only the failing IDs). [E] engine, [M] you
L1 [E/M] masses ending .0/.5 need a real constraint (integer count, saturation, boundary, clamp). Without E check it by hand: a displayed mass ending .0 or .5 means the arithmetic was skipped; recompute with more digits and keep it only if a constraint holds. L2 [E] albumen+yolk ≠ historical eggs. L3 [M] no alveograph metrics on gluten-free. L4 [E] every target validated. L5 [E] archetype ratios. L6 [E] spice ≤ 0.005/I_ar × total (1.0 mild, 1.5 default, 2.0 bark). L7 [E] retro unit ±1.5 %; an inferred fluid takes a volumetric unit, a solid a weight unit. L8 [E] no decimals in Q. L9 [E/M] every sub-matrix has an inferred target (E refuses one without) and the Targets block lists it. L10 [M] concordance quotes are real and ≥10 words (L11 same). L12 [M] printed total = FINAL_TOTAL_MASS. L13 [E] matrix sum = target mass. L14 [M] EFSA/FDA limits (safrole, coumarin e.g. cassia, heavy metals; animal-derived musk/ambergris: flag and substitute) logged in HACCP. L15 [M] bibliography only as constants. L16/L17 [E] bulk solids and flours never SOTTILE.
Anti-mirroring: modern = historical (<0.01 g) → `LINT_ERROR`; within 1 % and 0.1 g → accept, note "Historical Alignment Achieved".
Error strings: `LINT_ERROR: Identification missing or invalid|without source - <name>`, `Unidentified ingredient must use cat other - <name>`, `LINT_ERROR: Critical metrology routing violation - …`, `Unjustified termination <n>`, `Ingredient mirroring <n>`, `Total mirroring`, `Mass Mismatch (<m>)`, `L7|L8 <n>`; `RHEO_ERROR: [<m>] …` → retry, never abort.

## E. ENGINE I/O (`py <skill dir>/scripts/hrc_engine.py payload.json` or `from hrc_engine import run`)
```
{"year","zone","evap_min":5.0,"inferred_targets":[§B],
 "geometry":{"D":cm,"merlon":cm,"crust":[a,b,c,d,e],"filling":[a,b,c,d,e],"crust_matrix","filling_matrix"},   // tart-like shells only, cm
 "matrix_mass_g":{"m":g}  |  "matrix_volume_ml":{"m":ml},       // every matrix without geometry needs one (volume × density = mass)
 "hist":[{"name","variant","cat","vol","qty_native":"1 1/2"|null,"unit","src_text","unit_g"|"unit_ml","unit_src","units":[{"unit","unit_g"|"unit_ml","unit_src"}],"blend":true,"fluid_rho","proxy":"source text","taxon","egg":true|"albumen"|"yolk","parts":[[n,"name","taxon"]]}],   // `unit` = a unit written in the recipe (count nouns too); `src_text` required with qty_native (the unit must occur in it); `unit_src` required with unit_g|unit_ml; egg rows take their mass from the engine egg model
 "ingredients":[{"name","variant","mw","sub_matrix","cat","vol","phase","function","seed","hist_ref","taxon","rho","eo_pct","state","i_ar","perishable":true|false,"ident":{"status":"KNOWN"|"RESEARCHED"|"UNKNOWN","src":"input|modern term|URL + page"},"just","inferred":true,"egg":"albumen"|"yolk"}]}  // `ident` required on every row except eggs and surface rows; `hist_ref` required on every non-surface row
```
Surface row inside `ingredients`: `{"name","sub_matrix","type":"pure_surface_density","density_g_cm2"}`. `zone` 0=IT 1=IQ 2=FI 3=PT 4=CH 5=SCT 6=BAV 7=EN 8=ES 9=AND 10=FR 11=DE 12=AT 13=BE 14=NL 15=US. `phase` fluid|lipid|solid|gas; `function` starch_network|protein_coagulation|lipid_plasticization|emulsifier|osmotic_solute|ionic_solute|volatile_aromatic|hydrolat|hydration; `cat` flour|spice|sugar|salt|drug|hydrolat|fat|meat|cheese|herb|legume|seed|liquid|other. Eggs: two rows, `egg:"albumen"` and `egg:"yolk"`, `seed` = grams each (never a count; independent of whole eggs). The egg model (year, zone) serves only the historical line: `hist` row `egg:true` with the text count prints total albumen g + total yolk g; no quantity → nearest fraction of the model egg. `seed` = your zero-base modern estimate in grams, never a historical copy; fluids with a known density carry `rho` (without it only one dimension is printed).
E projects fluid/lipid groups onto archetype bounds, scales each matrix to its mass, applies floors (SOTTILE ≥0.01 g, others ≥0.1 g) and the aromatic cap, validates. E refuses: a modern row without a hist row; a hist row without a modern row; a sub-matrix without a target; an `unknown` row; a modern `name` that differs from its hist `name` (eggs and blend components excepted); two hist rows with the same name and variant; a sub-matrix that mixes variants; a measure without `unit_src`; a quantity without `src_text`; a blend whose modern row names differ from its `parts`; an inferred fluid without a volumetric unit; a volume without `fluid_rho`/`rho`. State carries `sig` (hash of the printed lines). It returns (compact): `errors, rheology_passed, rheology_errors, notes, confidence, penalties, hist_lines, modern_lines, state, render{telemetry[], density[], geometry[], windows, haccp[]}` — `render` holds finished, rounded lines to paste. Pass `"loop":N` (1-based run number; at N≥3 with rheology still failing E reports CONVERGENCE_PARTIAL, LOW). `--full` adds raw masses, aw, egg model, thresholds. `variant` (hist and ingredient rows, same text on both): label of an "or"-variant; E prints ` (variant: label)` and one mass balance per variant; give each variant its own `sub_matrix`. `mw`: molar mass of an osmotic solute (default 342.3; honey, fructose, glucose 180); the engine never reads names. A count noun whose unit is its own name prints once; an egg without a written count takes an integer or a half of the model egg.
**Linter**: `py <skill dir>/scripts/hrc_engine.py --check dossier.md` (a whole dossier or only the two lists) checks line shapes, mass decimals, modern name = historical name, one row per term and variant, no 0 g row, no DATA UNKNOWN modern row, no `[Inferred: DATA UNKNOWN]` while a table unit is in use, no comment after a name, every historical ingredient present in both lists, round masses (L1), headers, State and its `sig`. Modern list decimals: solids (sugar included) and fluids 1, spices, salt 2 (checked). Exit 1 on any FAIL; WARN needs a human look. The engine output always passes.

## G. LANGUAGE (ASD-STE100, applied while writing)
- 100 %: Technical Steps, State Vectors, Mechanical Action, Resting Curve, Checkpoint, HACCP, Contingency, Mise en Place. 60 %: TA, Concordance, Batch Comparative. 0 %: ingredient names, taxonomy, historical units, formulas, numbers.
- One instruction per sentence, ≤20 words; active voice; simple tenses; "must" never "should"; articles; noun clusters ≤3 words; dash list for ≥3 actions; one term per concept; define abbreviations once; no metaphors, hedges, marketing words.
- Locked terms — processes: gelatinize, coagulate, denature, hydrate, retard, emulsify, crystallize, aerate, temper, proof, rest, chill, scald, sear. Thermodynamics: core temperature, water activity, phase transition, boiling point, gel point, syneresis, Maillard reaction. Equipment: whisk, spatula, rolling pin, probe thermometer, sieve, bain-marie. Ingredients: the exact E `name`.
